# Design Tokens

## Color Palette

- **Background**: `--zm-bg` (e.g., `#0D0D1A` - A very dark, near-black purple)
- **Surface**: `--zm-surface` (e.g., `#1A1A2E` - A dark blue-purple for cards and panels)
- **Text**: `--zm-text` (e.g., `#FFFFFF` - White for primary text)
- **Muted Text**: `--zm-text-muted` (e.g., `#A0A0B0` - A light gray for secondary text)
- **Primary**: `--zm-primary` (e.g., `#8B5CF6` - The main purple accent for buttons and links)
- **Primary Ghost**: `--zm-primary-ghost` (e.g., `rgba(139, 92, 246, 0.2)` - A transparent version of the primary color for hover states or backgrounds)
- **Accent**: `--zm-accent` (e.g., `#FACC15` - A contrasting color like yellow or gold for highlights, if needed)

## Border Radius

- **Default**: `--zm-radius` (e.g., `8px`)

## Spacing

- **Small**: `--zm-gap-sm` (e.g., `8px`)
- **Medium**: `--zm-gap-md` (e.g., `16px`)
- **Large**: `--zm-gap-lg` (e.g., `32px`)

## Typography Scale (using clamp for responsiveness)

- **H1**: `--zm-h1` (e.g., `clamp(2.5rem, 5vw, 4rem)`)
- **H2**: `--zm-h2` (e.g., `clamp(2rem, 4vw, 3rem)`)
- **H3**: `--zm-h3` (e.g., `clamp(1.75rem, 3.5vw, 2.5rem)`)
- **H4**: `--zm-h4` (e.g., `clamp(1.5rem, 3vw, 2rem)`)
- **H5**: `--zm-h5` (e.g., `clamp(1.25rem, 2.5vw, 1.75rem)`)
- **H6**: `--zm-h6` (e.g., `clamp(1rem, 2vw, 1.5rem)`)

## 3. Core User Flows & CTA Routing

### Flow 1: Prospect Explores Services and Views Pricing
1. **Entry Point:** Home Page (`/`)
2. **Action:** Clicks on a Service from the main navigation or a services grid.
3. **Destination:** Specific Service Page (e.g., `/services/web-design`).
4. **Action:** Reads about the service, sees value props.
5. **Primary CTA:** Clicks "View Pricing".
6. **Destination:** Pricing Page (`/pricing`).
7. **Action:** Compares plans, decides on a tier.
8. **Primary CTA:** Clicks "Book Free Consultation".
9. **Destination:** GHL Calendar/Form embed for lead capture.

### Flow 2: Prospect Goes Directly to Pricing
1. **Entry Point:** Any page with the main navigation.
2. **Action:** Clicks "View Pricing" in the header or a contextual link.
3. **Destination:** Pricing Page (`/pricing`).
4. **Action:** Compares plans, potentially uses the "Compare Features" table.
5. **Primary CTA:** Clicks "Book Free Consultation".
6. **Destination:** GHL Calendar/Form embed.

### Flow 3: Custom Solution Inquiry
1. **Entry Point:** Pricing Page (`/pricing`).
2. **Action:** User's needs don't fit the predefined plans.
3. **Secondary CTA:** Clicks "Discuss Custom Solution".
4. **Destination:** Contact form or dedicated consultation booking page.

### Flow 4: CRM Software Inquiry
1. **Entry Point:** Any page with the main navigation.
2. **Action:** Clicks the secondary CTA "Get CRM Software".
3. **Destination:** External GHL link or a dedicated landing page explaining the CRM offer.

## 4. Page Cross-linking Strategy

- **Home Page:** Links to all primary Service pages and the Pricing page.
- **Service Pages:** Link back to the main Pricing page and to the consultation booking form.
- **Pricing Page:** Links to the consultation booking form for each plan.
- **About Page:** Links to the consultation booking form.
- **Footer:** Provides global access to all key pages.
